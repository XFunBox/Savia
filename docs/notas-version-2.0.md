# Savia 2.0.0

Primera versión pública con la identidad Savia. Incluye las funciones de Ahorro 1.0.0 y un identificador Android nuevo.

## Instalación y datos

Savia se instala como una aplicación independiente de Ahorro 1.0; no es una actualización directa. Android no migra los datos entre ellas.

Para llevar los datos existentes:

1. En Ahorro, exporta una copia JSON desde Ajustes.
2. Instala Savia.
3. En Savia, importa la copia desde Ajustes y verifica los datos antes de desinstalar la app anterior.

Las copias JSON no están cifradas. La firma de la APK se mantiene para futuras actualizaciones de Savia; esta release no representa una publicación en Google Play.

## Incluye

- Búsqueda de movimientos por categoría, nota o importe.
- Repetición de gastos variables con revisión antes de guardar.
- Funcionamiento local, sin cuenta ni telemetría.
